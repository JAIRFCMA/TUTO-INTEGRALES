Integrales Trigonométricas

Técnicas especiales para integrar productos de funciones trigonométricas

Casos Principales

Identidades útiles:
  • \( \sin^2 x + \cos^2 x = 1 \)
  • \( 1 + \tan^2 x = \sec^2 x \)
  • \( \sin^2 x = \frac{1 - \cos 2x}{2} \)
  • \( \cos^2 x = \frac{1 + \cos 2x}{2} \)
  • \( \sin x \cos x = \frac{\sin 2x}{2} \)

Estrategias por Caso

\( \int \sin^n x \cos^m x \, dx \)

Si n es impar: guardar un seno y convertir el resto a cosenos

Si m es impar: guardar un coseno y convertir el resto a senos

\( \int \tan^n x \sec^m x \, dx \)

Si m es par: guardar \( \sec^2 x \) y convertir el resto a tangentes

Si n es impar: guardar \( \sec x \tan x \) y convertir el resto a secantes

Productos con diferentes ángulos

Usar identidades de producto a suma:

\( \sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)] \)

Potencias pares de seno o coseno

Usar identidades de ángulo doble para reducir la potencia:

\( \sin^2 x = \frac{1 - \cos 2x}{2} \)

Ejemplos Resueltos

\( \int \sin^3 x \cos^2 x \, dx \)

1. Separamos \( \sin^3 x = \sin^2 x \cdot \sin x \)

2. Convertimos \( \sin^2 x = 1 - \cos^2 x \)

3. Sustituimos y hacemos \( u = \cos x \):

\( \int (1 - u^2) u^2 (-du) = \frac{u^5}{5} - \frac{u^3}{3} + C \)

4. Solución: \( \frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C \)

\( \int \sec^4 x \, dx \)

1. Separamos \( \sec^4 x = \sec^2 x \cdot \sec^2 x \)

2. Usamos \( \sec^2 x = 1 + \tan^2 x \)

3. Sustituimos \( u = \tan x \):

\( \int (1 + u^2) du = u + \frac{u^3}{3} + C \)

4. Solución: \( \tan x + \frac{\tan^3 x}{3} + C \)

Consejos Prácticos

  • Memoriza las identidades fundamentales
  • Identifica si las potencias son pares o impares
  • Para tangentes/secantes, recuerda las derivadas
  • Considera usar sustitución universal en casos complejos

Errores Comunes

  • Aplicar mal las identidades trigonométricas
  • No considerar todas las estrategias posibles
  • Olvidar el signo menos al derivar coseno
  • Confundir las integrales básicas
