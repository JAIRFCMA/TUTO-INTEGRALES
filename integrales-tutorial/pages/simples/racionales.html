Método de fracciones parciales para integrar cocientes de polinomios

Método de Fracciones Parciales

Pasos generales:
  1. Verificar si el grado del numerador es mayor o igual al denominador (división polinomial)
  2. Factorizar completamente el denominador
  3. Descomponer en fracciones simples
  4. Determinar los coeficientes
  5. Integrar cada término por separado

Casos de Factores

Factores Lineales Distintos

\( \frac{P(x)}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b} \)

Factores Lineales Repetidos

\( \frac{P(x)}{(x-a)^n} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_n}{(x-a)^n} \)

Factores Cuadráticos Irreducibles

\( \frac{P(x)}{(ax^2+bx+c)} = \frac{Ax+B}{ax^2+bx+c} \)

Factores Cuadráticos Repetidos

\( \frac{P(x)}{(ax^2+bx+c)^n} = \frac{A_1x+B_1}{ax^2+bx+c} + \cdots + \frac{A_nx+B_n}{(ax^2+bx+c)^n} \)

Ejemplo Resuelto

\( \int \frac{2x+3}{(x-1)(x+2)} dx \)

1. Descomponemos: \( \frac{2x+3}{(x-1)(x+2)} = \frac{A}{x-1} + \frac{B}{x+2} \)

2. Encontramos A y B: \( 2x+3 = A(x+2) + B(x-1) \)

3. Resolviendo: \( A = \frac{5}{3}, B = \frac{1}{3} \)

4. Integramos: \( \frac{5}{3} \ln|x-1| + \frac{1}{3} \ln|x+2| + C \)

Consejos Prácticos

  • Siempre verificar primero si se puede simplificar
  • Para encontrar coeficientes, usar valores estratégicos de x
  • Recordar que \( \int \frac{1}{x} dx = \ln|x| + C \)
  • Para términos cuadráticos, completar el cuadrado si es necesario

Errores Comunes

  • No verificar el grado del numerador
  • Factorización incorrecta del denominador
  • Olvidar el valor absoluto en los logaritmos
  • Confundir los casos de descomposición
