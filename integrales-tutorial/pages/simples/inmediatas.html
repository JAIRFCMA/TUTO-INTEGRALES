Integrales Inmediatas

Las integrales más básicas que se resuelven directamente aplicando fórmulas fundamentales

Tabla de Integrales Básicas

Función Integral
\( \int k \, dx \) \( kx + C \)
\( \int x^n \, dx \) \( \frac{x^{n+1}}{n+1} + C \) (n ≠ -1)
\( \int \frac{1}{x} \, dx \) \( \ln|x| + C \)
\( \int e^x \, dx \) \( e^x + C \)
\( \int \sin x \, dx \) \( -\cos x + C \)
\( \int \cos x \, dx \) \( \sin x + C \)

Ejemplos Resueltos

Ejemplo 1

\( \int 3x^2 \, dx = 3 \cdot \frac{x^{3}}{3} + C = x^3 + C \)

Ejemplo 2

\( \int (2x + 5) \, dx = 2 \cdot \frac{x^2}{2} + 5x + C = x^2 + 5x + C \)

Ejemplo 3

\( \int \left( \frac{1}{x^2} + e^x \right) \, dx = \int x^{-2} \, dx + \int e^x \, dx = \frac{x^{-1}}{-1} + e^x + C = -\frac{1}{x} + e^x + C \)

¿Qué son?

Las integrales inmediatas son aquellas que pueden resolverse directamente aplicando las fórmulas básicas de integración sin necesidad de realizar transformaciones o cambios de variable.

Consejos

  • 1. Identifica si la integral coincide exactamente con una fórmula básica
  • 2. Aplica propiedades de linealidad para separar términos
  • 3. Verifica tu resultado derivando
