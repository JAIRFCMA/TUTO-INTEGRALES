# 🧮 Tutorial Interactivo de Cálculo Integral

![Banner del Proyecto](./assets/banner-matematicas.png)

## 📖 Descripción

Repositorio educativo completo sobre cálculo integral que incluye:

- **Integrales Simples**: Técnicas básicas y avanzadas
- **Integrales Dobles**: Geometría y aplicaciones en el plano
- **Integrales Triples**: Sistemas de coordenadas 3D
- **Ejercicios Resueltos**: Más de 50 ejemplos paso a paso

## ✨ Características Destacadas

| Sección | Contenido | Nivel |
|---------|-----------|-------|
| 📈 Simples | Inmediatas, sustitución, partes, trigonométricas | Básico-Avanzado |
| 📊 Dobles | Iteradas, polares, cambio de variables | Intermedio |
| 🧊 Triples | Cilíndricas, esféricas, aplicaciones físicas | Avanzado |
| 🎯 Ejercicios | Problemas resueltos con explicación detallada | Todos los niveles |
